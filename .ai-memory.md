# ROUTINE MEMORY: Project Genevn Kernel
**Target:** Moto G Stylus 5G 2023 (genevn)
**SoC:** SM6450 (Snapdragon 6 Gen 1)
**OS:** Android 14 (Kernel 5.10 / GKI 1.0)

## Technical Decisions
- **Compiler:** MUST use Clang/LLVM 12. (Version 16 causes errors).
- **Security:** Integrate KernelSU Next and SusFS (Stealth Root).
- **Pentesting:** Integrate cnet Hunter (NetHunter Pro) patches.
- **Image Strategy:** The ramdisk must be split between 'boot' and 'recovery' because the final image is too large for the boot partition.
- **Headers:** 4096k page size, LZ4 compression.

## Build Progress
- Environment is set up in GitHub Codespaces.
- Static binaries are required for ER/FS tools to run on-device.
- Current focus: Finalizing the ramdisk split script and SusFS integration.
